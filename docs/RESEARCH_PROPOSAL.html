01. 立项背景与我们要解决的本质问题

在量化投资的实际研发流程中，初期的策略探索往往高度依赖量化分析师的人工经验：提出假设、试算参数、调整过滤条件、复盘账本。这一过程耗时冗长，且极度依赖直觉。随着大语言模型（LLM）的成熟，业内开始尝试引入大模型协助生成量化逻辑。然而，在现有公开实践与学术尝试中，普遍存在两大严重脱离实盘的弊端：

  • 痛点一：回测环境中的隐性作弊（Lookahead Bias & Frictionless Trap）
    很多基于脚本的简易回测存在严重前视偏差（例如在 T 日收盘计算信号并在 T 日收盘价成交、中心化滚动均线、反向填补缺失值等）。更严重的是，模型生成的策略往往依赖高频次来回翻转来在样本内“刷出好看的夏普比率”，一旦计入真实的券商佣金和滑点磨损，策略净收益往往立刻崩溃甚至巨额亏损。
  • 痛点二：大模型盲目搜索与无底线过拟合（Snooping & Hallucination）
    直接让 LLM 自由手写 Python 回测代码，不仅语法报错频发，模型还会为了迎合目标函数，无意或恶意在测试集上调整参数。这种“假创新”在真实样本外（Out-of-Sample）面对未见过的市场时毫无抵御能力。
本研究的核心问题（Research Question） 如果我们彻底锁死底层的物理规则（严格无前视偏差、强制 T+1 开盘撮合、计入真实交易摩擦），并在数据流上做严格的 Train / Validation / Test 物理隔离，那么通过构建由“研究员（Researcher）”与“审查员（Reviewer）”组成的多智能体框架，能否让大模型在受限参数空间内，自主迭代出低换手、强抗摩擦、在真实样本外依然具备稳健表现的有效策略？

02. 项目研究目标 (Specific Objectives)

本项目不追求花哨的 AI 叙事，力求在真实的工程约束下实现可复现、可度量的量化闭环，具体目标包括三项：

1. 搭建透明无黑盒的因果回测基座

基于原生 Python/Pandas 构建纯面向对象回测引擎，物理锁死 T+1 撮合与 10bps 双边摩擦，实现现金、持仓、市值、权益、盈亏与手续费 6 大账本闭环结算，杜绝任何数据穿透可能。

2. 设计受控的 Agent 基础设施

不让大模型直接写易错的 Python 代码，而是制定规范的 StrategySpec 契约；通过 Evaluator 将大模型提出的量化假设翻译为可执行信号，屏蔽跨段未来信息。

3. 科学度量智能体拓扑与过拟合

在固定相同 LLM 智力基准下，对比单智能体（Solo）、双智能体审校（Reviewer Gate）及并行对抗（Dual-Agent）等组织形态在抑制过拟合落差（Overfitting Gap）上的客观效果。

3.1 严格因果的三段式时序隔离 (Train / Val / Test)

为彻底杜绝大模型“作弊”或“先看答案再答题”，我们将 12 年的标普 500（SPY 2015-2026）日频行情做物理切割：

数据分段 (Split) 对应时间跨度 样本量 主要宏观市场特征 访问权限与使用规则
Train (训练/搜索段) 2015-01 至 2022-01 1,765 天 (60%) 低利率慢牛，偶发事件性熔断 仅供 Researcher 反复试错。大模型只能看到该段的回测反馈。
Validation (验证/选择段) 2022-01 至 2024-05 588 天 (20%) 美联储激进加息熊市，宽幅拉锯震荡 大模型完全不可见。仅由协调器在迭代收尾时客观挑出胜出策略。
Test (封存测试段) 2024-05 至 2026-09 590 天 (20%) 降息预期与科技股单边主升浪 绝对保密，全局仅运行一次。只在最终定稿后用于审计真实泛化表现。
关于因果隔离与真实账本结算的硬性约束： 进入 Validation / Test 分段时，为避免移动均线等指标开头出现 NaN，系统采用单向历史缓冲（Lookback Buffer）预热指标，计算完毕后严格按当前分段索引截取。严禁使用 bfill（反向倒灌未来数据），每段回测的初始资金（100,000 美元）与持仓独立重置，彻底切断跨时间段的资金串扰。同时，回测全流程直接基于标普 500 ETF 的全复权行情（Adjusted OHLCV）开展，股息分红已自然体现在复权收益中（杜绝独立分红账本导致的收益双重核算），并保留首日收益观察对齐真实期数。

3.2 策略契约与沙盒执行机制

大模型不直接接触 Pandas 代码，其输出必须且仅能遵循结构化 JSON 数据规范（StrategySpec）：

  • signal_type：允许尝试的基础动量或震荡逻辑（如 momentum 均线突破、macd 差离值）；
  • params：受约束的参数区间（如 window ∈ [2, 260]）；
  • hypothesis：模型必须用一段金融逻辑文本解释其调整参数的微观动机；
  • allowed_regimes：允许交易的市场量价象限（Q1~Q4，用于后续市场感知过滤）。

3.3 前置审查员（Reviewer）的防御门禁

在任何策略进入回测引擎之前，必须通过 Reviewer 的三道检查，未通过则直接打回并扣除尝试次数：

  1. 参数边界强校验：过滤快线大于慢线等荒谬输入；
  2. 历史策略去重（Deduplication）：比对历史尝试库，阻止大模型原地打转或提出同质参数；
  3. 假说完整性检查：剔除空泛无实际经济学依据的随机构想。

04. 实验设计与控制变量矩阵

为评估 Agent Infra 的真实有效性，实验严格控制单一变量，对比四种宏观架构（Topologies）：

实验架构代号 组织形态 (Topology) 智能体配置 验证的核心科研假说
Framework A 手写经典基准 (Baseline) 无 AI，固定经典参数 (SMA50, MACD) 作为传统被动量化参考线。
Framework B 单智能体探索 (Solo Researcher) 单 Researcher，无 Reviewer，FIFO 记忆 测试大模型在单兵作战、仅凭简单反馈时的探索效率与是否会过拟合。
Framework C 双智能体协作 (Researcher + Reviewer) 增加中心化前置审查拦截与反省反馈 核心关注：前置质检能否有效遏制无效搜索，逼迫大模型寻找更有泛化力的策略？
Framework D 多智能体并行对抗 (Dual Researcher) 两个 Researcher 独立并行提出，统一挑优 测试分流搜索预算、并行竞争是否比单兵深挖更具性价比。
严密的控制变量原则（Controlled Variables）： 所有实验组统一使用相同的底层大模型（deepseek-chat）、相同的温度参数（0.7）、相同的单边 5bps 摩擦、相同的 3 段数据切分，并在 5 组独立随机种子（Seed 42 ~ 46） 下重复运行，报告均值与标准差，彻底消除偶然单次跑分带来的偏差。

05. 初步验证与可行性证据 (Proof of Concept)

我们已在本地完整搭建了整套环境，并调用实际大模型接口完成了第一阶段基准评测。初步实证数据揭示了极具价值的结论：

评测架构 Validation 夏普 (验证/选择段) Test 封存测试段夏普 (Holdout) 过拟合落差 (Overfit Gap) 测试段真实收益 测试段交易次数
A: 手写基准 0.3135 0.1931 (大幅衰退) +0.1204 (严重衰减) +3.88% 56 次 (摩擦损耗重)
B: 单智能体 0.3031 ± 0.103 1.2159 ± 0.069 -0.9128 ± 0.141 +33.78% 12.8 次 (低频稳健)
C: 审校协作 0.2565 ± 0.002 1.1571 ± 0.166 -0.9007 ± 0.166 +35.09% 9.8 次 (换手最低)
D: 并行对抗 0.2549 ± 0.000 1.2913 ± 0.000 -1.0364 ± 0.000 +37.71% 11.0 次 (精准收敛)
初步量化发现与现实启示：
  1. 为什么手写基线在真实摩擦下失效？ 经典 MACD 在测试段频繁开平仓 56 次，双边摩擦严重蚕食收益，在全复权回测下测试段总收益仅有 3.88%，且出现了明显的样本外性能衰减（衰减 Gap 为 +0.1204）。
  2. 智能体为何在测试段跑出稳健高夏普（1.15 ~ 1.29）？ 面对摩擦和波动率反馈，大模型自发收敛至中低频长周期趋势（如 120~200 天均线），测试段平均交易次数由基线的 56 次暴降至 10~13 次（换手率降幅达 75% 以上），既稳健度过了 2022-2024 年震荡市，更在 2024-2026 单边主升浪中近乎吃满波段，测试段平均收益达 +33% ~ +37%。
  3. Reviewer 审查协作（Framework C）的真实功用：在 5 组独立种子测试中，Framework C 在选择阶段表现出惊人的方差压制能力（Validation 夏普标准差仅 0.0022），同时测试段调仓次数压缩至全场最低的 9.8 次，平均收益率提升至 +35.09%，有效阻断了重复短视参数的试错内耗。

06. 主流智能体范式借鉴与后续拓展实验路线 (Roadmap & Architectural Paradigms)

在完成阶段一的宏观拓扑对比后，为进一步探究如何帮助大模型在有限试错预算下抑制过拟合、提出真正具备金融经济学支撑的有效策略，我们系统梳理了当前学术界与工业界成熟的六大智能体设计范式，并结合本项目的原生量化内核，设计了以下可落地、可度量的单变量消融实验方向：

1. SOTA 锚定与经验外脑 (Memory-Augmented)

机制：放弃易丢失全局优胜解的朴素先进先出（FIFO）遗忘队列，在提示词中永久置顶“历史全局表现最优策略（SOTA）”，同时记录高换手或大回撤的“失败禁区”。
实验设计：对比普通滑动记忆 vs. SOTA 锚点记忆，验证锚定基准能否杜绝智能体在多轮迭代后期原地打转或目标迷失。

2. 语言反思自省闭环 (Reflexion / Self-Refine)

机制：不单单把夏普比率等数字指标喂给大模型，而是强制模型在收到回测账本后输出一段 100 字左右的结构化复盘备忘录，诊断亏损原因并带入下一轮推理。
实验设计：对比“纯数字反馈” vs. “数字 + 自然语言反思日志”，评估引入因果推演对降低试错轮数与压缩换手率的贡献。

3. 分层调度与交替优化 (Hierarchical Co-Optimization)

机制：借鉴微软 RD-Agent 的分层思想。上层调度器（轻量启发式或多臂老虎机）负责决定“本轮优化均线信号、市场状态过滤还是波动率缩放比例”；下层专职产出参数。
实验设计：对比单一大脑混合调参 vs. 上下层解耦交替优化，评估在多维度参数空间下的收敛稳定性与可解释性。

4. 角色分工专业流水线 (SOP Role Specialization)

机制：参考软件工程标准作业程序（SOP），将投研任务拆分为“宏观环境分析员（识别当前市场状态 Regime）”、“择时策略研究员”与“风控合规官（专抓换手与杠杆违规）”。
实验设计：测试多角色提示词解耦是否比单一综合 Researcher 更少出现逻辑混乱和回测透支。

5. 思维树与启发式剪枝 (Tree of Thoughts / LATS)

机制：放弃线性串行循环，采用树状推演。单轮分叉出若干不同类型的假说原型（如长周期动量、短周期突破、MACD），在训练集初步打分后剪除无效分支，仅保留优势节点深挖。
实验设计：在相同调用预算下，对比 8 轮串行探索 vs. 2×4 树状分支搜索的最终策略夏普分布与多样性。

6. 多智能体对抗辩论 (Multi-Agent Debate)

机制：设立“进攻派研究员”与专门翻找历史至暗时刻（如 2020 年熔断、2022 年加息）的“压力测试审校员”，二者相互辩驳后由仲裁器做最终裁决。
实验设计：测试对抗辩论机制是否比单一规则审核更有力地削减最极端尾部风险（Tail Risk）。

07. 研究边界与客观局限性声明

为保持学术与工业研究的严谨性，本提案主动界定以下局限与假设：

  • 资产覆盖范围：当前实证以单品种（标普 500 ETF SPY）日频数据为核心。未来拓展方向为全市场多品种多资产配置。
  • 策略搜索空间：当前阶段重点考核动量突破、MACD 与波动率调节的参数化假说，尚未开放任意 Python 代码的无限制编写，以确保因果时序和语法的绝对稳定。
  • 计算与 API 成本控制：多智能体实验涉及反复的大模型调用，我们将探索预算硬性限制在每轮 4~8 次，并配合完全确定性的 MockLLM 基准以控制开销。
