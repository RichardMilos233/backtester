结论：

1. **预算对齐后 LLM 确实变好，但幅度不大**，+0.016 到 +0.047 percentile_val。早停不是主因。
2. **仍然没有超过 R-random 的 0.891**。三个架构都还在 0.78–0.81 区间，差距约 0.08–0.11。
3. **代价明显上升**：token 消耗增加约 30–45%，C-sota 和 C-corr 的审查打回次数分别升到 33 和 85（早停版是 15 和 54），因为跑满预算自然会有更多重复提案被打回。
4. 三个 C 变体之间置信区间依旧重叠，架构差异仍不显著。

所以早停只是次要因素。真正的瓶颈大概率是任务本身：格点只有 12,020 个 spec，随机抽 8 次就能到 0.89 分位，没有留下 LLM 靠推理取胜的空间。这正是启动 Layer 1–3（放开 vol/leverage/regime + 新增 mean_reversion/breakout/rsi/combo，格点扩到 17,010 / 153,090）的原因。下一步要在 v2 格点上重跑这三档。
